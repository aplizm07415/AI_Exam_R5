# 解説構造の比較案（承認待ち）

全2,463問へ反映する前の比較資料です。以下は同じ問題 `finance:S-5026`（正答：イ、750万円）を3方式で構造化した例です。内容ではなく、最も読みやすい「型」を選んでください。

## 案A：結論 → 解法 → 選択肢（推奨）

### 結論

**正答：イ（750万円）**

### 解法

1. 期末純資産：700 − 430 ＝ **270万円**
2. 当期純損益：810 − 900 ＝ **−90万円**
3. その他の純資産変動：130 − 110 ＝ **＋20万円**
4. 期首純資産：270 − (−90) − 20 ＝ **340万円**
5. 期首資産：410 ＋ 340 ＝ **750万円**

### 判断の軸

貸借対照表の関係は「資産＝負債＋純資産」。純資産の期中変動を逆算してから、期首資産を求めます。

### ミスしやすい点

- 当期は90万円の利益ではなく、**90万円の損失**です。
- その他変動は130万円ではなく、増加と減少の純額 **＋20万円**です。

### 難易度

**標準**：公式の暗記だけでは足りませんが、与件だけで4段階の計算が完結します。

## 案C：学習対話型

### まず何を出す？

期末資産と期末負債があるため、期末純資産を出します。

`700 − 430 ＝ 270万円`

### 次に何を戻す？

期中の変動は、純損失90万円とその他純増20万円。合わせて純資産を70万円減らしています。したがって期首純資産は期末より70万円多い340万円です。

### 最後の一手

期首資産＝期首負債410万円＋期首純資産340万円＝**750万円（イ）**。

### 自分で再確認

期首純資産340 − 純損失90 ＋ その他純増20 ＝ 期末純資産270。整合しています。
