
//メモ：再現答案の整形をするときのプロンプト。

以下の再現答案を出力ルールに従って整形してほしい。

【出力ルール】
テキスト取り扱いルール
	•	要約・修正・補完は禁止
	•	改行・記号（①②③など）も原文維持
	•	誤字があっても直さない（再現答案のため）

並び順ルール
	•	questions：設問番号昇順
	•	answers：
	•	score 降順（高得点 → 低得点）
	•	同点の場合は input_no 昇順

禁止事項
	•	分析コメントを出力しない
	•	説明文を混ぜない
	•	JSON以外のテキストを出力しない
	•	分割しない（1つのJSONのみ）で、コードブロックで送って欲しい。
JSON全体構造
{
    "case": "R01年度事例1",
    "questions": [
        {
            "question_no": 1,
            "points": 20,
            "answers": [
                {
                    "input_no": 1,
                    "score": 76,
                    "answer_text": "理由は、縮小する葉たばこ市場に対して自社のコア技術ではないメンテナンス分野で事業化したためである。"
                }
            ]
        }
    ]
}

【再現答案】
