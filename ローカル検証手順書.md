# <Githubを使ったローカル検証>GHCR（GitHub Container Registry）
	•	置き場所：ghcr.io/aplizm07415
	•	GitHub側のレジストリなので PATでdocker login が必要
	•	Azureがpullするには、イメージがpublicならそのまま、privateならAzure側に認証設定が必要

1.ローカルでコンテナイメージをビルド
```bash
docker build -t ghcr.io/aplizm07415/quiz-app:v50 .
```

2.ローカル検証
```bash
docker stop quiz-app-container >/dev/null 2>&1 || true && docker rm quiz-app-container >/dev/null 2>&1 || true && docker run -d -p 18000:8000 -e AZURE_STORAGE_CONNECTION_STRING="REDACTED_CREDENTIAL" -e QUIZ_BLOB_CONTAINER='exam-json' --name quiz-app-container ghcr.io/aplizm07415/quiz-app:v50
```
http://localhost:18000

(ローカル困ったらログ確認)
```bash
docker logs -f quiz-app-container
```
------------------------------------------------------
3.ghcr.io（GitHub Container Registry）に保存
```bash
docker push ghcr.io/aplizm07415/quiz-app:v31
```

4.secret登録1
```bash
az containerapp secret set --name quiz-app --resource-group example-resource --secrets storage-conn="DefaultEndpointsProtocol=https;AccountName=examplestorage;AccountKey=XXXX;EndpointSuffix=core.windows.net"
```

5.secret登録2
```bash
az containerapp secret set --name quiz-app --resource-group example-resource --secrets quiz-blob-container="exam-json"
```

6.環境変数として設定
```bash
az containerapp update --name quiz-app --resource-group example-resource --set-env-vars AZURE_STORAGE_CONNECTION_STRING=secretref:storage-conn QUIZ_BLOB_CONTAINER=secretref:quiz-blob-container
```

7.本番反映
```bash
az containerapp update --name quiz-app --resource-group example-resource --image ghcr.io/aplizm07415/quiz-app:v31
```
https://github.com/users/aplizm07415/packages/container/package/quiz-app

8.本番URL確認
```bash
az containerapp show --name quiz-app --resource-group example-resource --query "properties.configuration.ingress.fqdn" -o tsv
```
https://quiz-app.nicebeach-9190a7f6.japaneast.azurecontainerapps.io/

(本番ログ確認)
```bash
az containerapp logs show --name quiz-app --resource-group example-resource --follow
```
