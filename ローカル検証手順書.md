### 0. 認証方式の前提
- 空描き機能は **サーバー側セッション（HttpOnly Cookie）** で認証する。
- ログイン時に入力する値は `APP_ACCESS_TOKEN`。
- フロントにはトークンを埋め込まない。

### 1. ローカル `.env.local` の必須項目
```bash
AZURE_STORAGE_CONNECTION_STRING=...
QUIZ_BLOB_CONTAINER=exam-json
APP_ACCESS_TOKEN=（長いランダム文字列）
SESSION_SECRET=（APP_ACCESS_TOKENとは別の長いランダム文字列）
```

`SESSION_SECRET` を自動作成/更新する一行:
```bash
#grep -q '^SESSION_SECRET=' .env.local && sed -i '' "s/^SESSION_SECRET=.*/SESSION_SECRET=$(openssl rand -hex 64)/" .env.local || echo "SESSION_SECRET=$(openssl rand -hex 64)" >> .env.local
```
