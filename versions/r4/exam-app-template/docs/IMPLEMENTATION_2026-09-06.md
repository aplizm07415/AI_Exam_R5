## 演習・復習・模試

- 新規試行を未選択・解説非表示から開始し、採点は同じ試行につき一度だけ計上します。
- 中断した通常演習・日次演習を一覧から再開できます。問題順、選択、現在位置を復元し、離席や再読込中の時間を所要時間に加算しません。
- 当日の回答済み問題を日次割当から除外し、復習期限のある問題も組み込みます。
- 解説確認から24時間未満の再回答は練習履歴に残し、到達判定から除外します。過去の解説を再表示した時点も記録します。旧版の同一セッション内の重複採点は、最初の回答だけを判定に使います。
- 復習期限の初期値は1日・7日・30日。誤答後は1日へ戻し、正解による永久自動除外を廃止しました。利用者の手動除外は維持します。
- 模試は開始時から答案と期限を保存し、時間終了後の回答変更を拒否します。二重採点を防ぎ、採点済みの答案と結果を履歴から開けます。
- 通常演習で採点前にアプリ内電卓を使った場合も、練習実績と自力の到達判定を区別します。
- 一次模試の案内を電卓なしへ修正しました。外部で解く場合も [年度の公式案内](https://www.jf-cmca.jp/attach/test/r08/r08_1ji_annai.pdf) に沿う条件で記録します。

外部実施は教材名・日付・時間・対応項目・完了条件の自己申告、得点確認は異なるセットでの初見・時間内・電卓なし80点以上2回で確認します。通常問題の到達度、実施記録、本試験形式の得点は別の指標です。教材名の表記揺れを完全に同定する機能や、外部答案の自動検証はありません。

週の学習時間と残る3科目の免除確認状況を入力・保存できるようにしました。簿記合格前の財務系配分は文書に合わせ70/20/10へ統一しました。一次固有の財務論点を残すこと、一次が安定した段階で事例Ⅰ〜Ⅲも外部教材で練習する案を [学習設計](R4_STUDY_DESIGN.md) へ反映しています。入力時間を使った問題数の自動最適化や、二次答案の添削は未実装です。

難易度は元データの「※複雑」だけで発展へ分類しないようにし、索引を再生成しました。公式表を復元したS-4775とS-4839は、記号の読取・比率計算・定義に基づく合算として「標準」に固定し、表の数字の個数だけで発展へ移さないようにしました。現在の層別件数は60点1,775問、70点追加365問、80点追加312問です。分類変更と旧版の評価除外により、従来と到達度・開放状態が変わる場合があります。自動分類は引き続き候補であり、手動点検済みの体系ではありません。

科目別の必要問題数を満たしても、全体だけ40問固定で不合格になる処理を修正しました。80点追加層の法務が4問なら、全体必要数は財務10・運営10・法務4・中小10の合計34問です。セッション数・正答率など各科目の条件も満たす必要があります。60点チェックポイントの表示も、科目別必要数の合計へ揃えました。

## 保存と処理時間

未送信の変更・削除待ち・サーバーの削除済みIDを端末へ保存します。二端末の更新は項目・セッション・試行単位で統合し、採点済みの試行を新しいドラフトで上書きしません。採点通信中・新版取得中・中断からの再開中に同期が起きても、最新のセッションを参照します。削除されたセッションは復活させません。

表示中の問題より新しい版の回答状態が同期された場合は、古い画面の操作を止めて演習一覧へ戻します。再開時の問題取得中、通常演習中、新版の保存中のいずれも新しい回答・除外した選択肢を保持します。現在表示していない設問も確認し、同じ版の同期は演習を続行できます。

DB側は版とセッションと削除情報を一貫した読取で取得し、版の比較を含むトランザクションで保存します。旧JSONの移行中に競合した場合は再取得します。`results`・`mockResults`だけの旧形式もセッションへ移し、メモ保存で履歴が消えないようにしました。移行読込が完了していない直接保存でも、既存履歴を移してから状態を更新します。同じメモへの同時編集はローカルの未送信変更を優先する仕様です。

集計を科目・論点で索引化し、同じ状態を画面内で繰り返し評価する処理を共有しました。1万回答の合成履歴による手元Nodeの一回比較では、学習記録画面の処理は約5.5秒から約0.6秒でした。実ブラウザー・実端末の性能測定ではありません。
