# 解説形式（承認済み）

2026年8月16日に、案Cの思考順序を基礎とする形式で承認されました。

## 適用ルール

- 「まず」「次に」「最後に」などを使い、解答へ至る思考の順序を追えるようにする。
- 正答の記号・選択肢本文は解説に再掲しない。採点後の選択肢の色で示す。
- 難易度と注意点は解説に含めない。難易度データは出題制御用の内部情報としてのみ保持する。
- 「判断の軸」「選択肢の根拠」「結論」「解法」といった区切り見出しを置かない。
- 計算問題は、式、途中数値、検算の順が自然に追える文章にする。
- 知識・事例問題は、問われている論点、適用する規則、各記述との照合順が追える文章にする。
- 法令・制度・統計には、解説末尾へ公的出典と基準日を付ける。ただし「ファクトチェック」という見出しは置かない。

## 表示例

### 財務・会計 `finance:S-5026`

まず、期末の貸借対照表から純資産を求めます。資産700万円から負債430万円を引くと、期末純資産は270万円です。

次に、収益810万円から費用900万円を引き、当期純損失90万円を求めます。その他の純資産変動は、増加130万円から減少110万円を引いた20万円の純増です。

続いて、`期末純資産 ＝ 期首純資産 ＋ 当期純損益 ＋ その他の変動` に代入します。`270 ＝ 期首純資産 − 90 ＋ 20` なので、期首純資産は340万円です。

最後に、期首負債410万円へ期首純資産340万円を加えると、期首資産は750万円になります。`340 − 90 ＋ 20 ＝ 270` と期末純資産へ戻ることも確認できます。

### 経営法務 `law:S-CO-06-51`

まず、会社法335条2項が監査役の独立性を確保するための兼職禁止規定であることを確認します。その株式会社の取締役・支配人・使用人と、子会社の取締役・支配人・使用人・会計参与・執行役が禁止対象です。

次に、各記述に出てくる会社との関係と役職を、条文の列挙対象へ一つずつ照合します。親会社の監査役はこの項の列挙対象ではなく、兼職禁止に反したことから選任決議が当然に無効になるとも定められていません。

最後に、会社との関係が「その会社・子会社・親会社」のどれか、役職が条文に列挙されているか、記述された法的効果まで条文にあるか、という順に判定します。

[e-Gov法令検索・会社法335条](https://laws.e-gov.go.jp/document?lawid=417AC0000000086_20260624_508AC0000000046)（2026年8月16日確認）

### 中小企業経営・政策 `sme:15-2`

まず、この問題は現行制度の名称と支援内容を問うものとして扱います。現在の名称は「事業承継・引継ぎ支援センター」で、全国47都道府県に設置されています。

次に、後継者人材バンクは、後継者不在の事業者と創業希望者などを引き合わせる仕組みであることを確認します。旧称だけを示した選択肢では、基準日のない現行問題として正確に採点できません。

最後に、機関名、マッチング対象、基準日の3点が現在の公的資料と一致するよう、問題文と選択肢を改めてから採点対象へ戻します。

[中小企業庁・事業承継を実施する](https://www.chusho.meti.go.jp/zaimu/shoukei/implement_business_succession.html)（2026年8月16日確認）
