# 中小企業経営・中小企業政策 学習計画

## 60点コース（足切り回避・効率重視）

### 捨て論点の方針
本コースは、頻出論点に絞り込み、最小限の努力で60点確保を目指します。中小企業白書の細かすぎる統計数値や、利用頻度の低いマイナーな政策の暗記は避け、主要なキーワードと代表的な施策の概要理解に徹します。過去問でA・Bランクの論点を確実に得点源にすることが目標です。

### 第1部 中小企業経営（中小企業白書）
- [ ] **第1章 中小企業の動向**
  - [ ] 中小企業・小規模事業者の定義（製造業、卸売業、小売業、サービス業）
  - [ ] 企業数・従業者数における中小企業の割合
  - [ ] 開業率・廃業率の推移
  - [ ] 労働生産性の動向（大企業との比較）
- [ ] **第2章 成長・発展の姿**
  - [ ] 事業承継の現状と課題（親族内、従業員、第三者）
  - [ ] M&Aの動向
  - [ ] DX（デジタルトランスフォーメーション）の取組状況
  - [ ] 海外展開の動向
- [ ] **第3章 小規模企業の動向**
  - [ ] 小規模企業の現状と課題
