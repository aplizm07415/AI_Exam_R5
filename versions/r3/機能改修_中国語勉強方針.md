

# 中国語学習機能拡張：ロードマップと実装方針

## 1. コンセプト
- **「生きた中国語」の習得:** 単なる暗記ではなく、音声認識とAI対話を組み合わせた実践ツールの構築。
- **既存資産の活用:** HSK単語集や体系的な参考書をインプットソースとし、Geminiで高速にJSONデータ化する。
- **ハイブリッド学習:** 資格試験（診断士）で培ったクイズエンジンをベースに、語学特有の「音」の機能をアドバンスドに追加。

## 2. 拡張機能一覧 (優先順位順)

### Phase 1: リスニング・視覚強化 (難易度: 低)
- **音声合成 (TTS) 連携:** - Web Speech APIを使用し、中国語の漢字・ピンインをネイティブ音声で自動再生する機能。
- **ピンイン・トグル機能:** - 漢字/ピンイン/意味をボタン一つで出し分け、脳への負荷を調整するUI。
- **多角的データ構造への変更:** - JSONに `pinyin`, `audio_focus`, `scene` 等のフィールドを追加。

### Phase 2: スピーキング・アウトプット強化 (難易度: 中)
- **音声認識 (STT) 判定:** - ユーザーの発音をブラウザで拾い、ピンインや声調（トーン）が正しいか判定する「音読正誤機能」。
- **チャンク学習モード:** - 単語単体ではなく、参考書にある「よく使う会話フレーズ」の塊で出題・判定。

### Phase 3: AI対話・動的生成 (難易度: 高)
- **Gemini API インタラクティブ・チャット:** - 特定のシチュエーション（例：レストラン、空港）を設定し、Geminiとフリートーク＆リアルタイム添削。
- **動的JSON生成スクリプト:** - Gemini CLIを用い、最新の中国語ニュースやSNSから「今日の生きたフレーズ」を抽出し、Blob Storageへ自動デプロイ。

## 3. インプットソースの活用方針
- **HSK単語集:** 語彙の土台（級別）として利用。
- **体系的参考書:** 場面別・文法別の「シナリオデータ」としてJSON化。
- **データ化手法:** GeminiのOCR機能とプロンプトを活用し、画像やテキストから直接「問題・解説・ピンイン」のJSONを生成する。

## 4. 実装のための技術スタック変更点
- **Frontend:** React + Web Speech API (SpeechSynthesis / SpeechRecognition)
- **Backend:** Azure Container Apps (現状維持)
- **Data:** Azure Blob Storage (JSONデータの格納・更新)
- **AI Tooling:** Gemini CLI (データ生成・変換用)

## 5. Geminiへの具体的依頼プロンプト例
- 「この参考書の画像から、中国語・ピンイン・意味を抽出し、既存のquiz-app用JSON形式に変換して。」
- 「ReactでWeb Speech APIを使って、特定のテキストを中国語で読み上げる関数を作成して。」
- 「ユーザーの発音した中国語と、正解のピンインを比較して一致率を出すロジックを提案して。」
